# Jiaqi Yu — Personal homepage

A static personal homepage with a full-screen interactive line mountain.

- Drag to rotate.
- Click to trace the contours.
- Double-click to unfold or reunite the layers.
- Keyboard: arrow keys, Space, Enter, Escape.

Serve this directory using any static web server. The entry point is `index.html`. No build step is required. Fonts are bundled with their OFL licenses in `assets/fonts/`.
